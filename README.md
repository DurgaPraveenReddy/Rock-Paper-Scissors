Rock Paper Scissors Game

A classic interactive implementation of the Rock Paper Scissors game, developed as part of The Odin Project's Foundations course.

Key Features
 * Core Logic: Robust implementation of the game's rules using JavaScript functions, including accurate handling of win, loss, and tie conditions.
 * User Interface: Utilizes HTML buttons for player input and DOM manipulation for displaying real-time results and scores.
 * Game Flow: Manages a continuous match, tracking scores for both the human player and the computer opponent.
 * Victory Condition: Automatically declares the final winner when a player's score reaches 5.

Technologies Used
 * HTML5: Provides the structural foundation and interactive elements (buttons).
 * CSS3: Styles the interface, including the visual diagram of the game's logic.
 * JavaScript (ES6): Contains all the functional logic, event handling, and dynamic content updates.

Setup and Execution
To run the game locally:
 * Clone this repository.
 * Open the index.html file in any modern web browser.
 * The game is played by clicking the "Rock," "Paper," or "Scissors" buttons.
